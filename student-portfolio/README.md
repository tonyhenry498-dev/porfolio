# Agbeble Tony | Student Portfolio & Academic Planner
COS 106 – Introduction to Web Technologies (Term Project)

A responsive multi-page website built with HTML5, CSS3 and vanilla JavaScript.

## Structure
```
student-portfolio/
├── index.html        Homepage
├── about.html        About (table, lists, audio, video)
├── projects.html     Projects (filterable) and summary table
├── planner.html      Academic planner (JS, localStorage)
├── contact.html      Contact form (JS validation)
├── css/style.css     External stylesheet
├── js/main.js        Navigation, greeting, footer year, project filter
├── js/planner.js     Add / complete / delete / filter tasks
├── js/contact.js     Form validation
├── images/profile.svg
└── media/sample.wav
```

## Before you submit
1. Replace the GitHub, LinkedIn and email links in contact.html and projects.html.
2. Replace `images/profile.svg` with your photo and update the `src` in about.html.
3. Fill in your secondary and primary school names in about.html.
4. Replace `media/sample.wav` and the video source with your own media.

## Hosting (GitHub Pages)
1. Create a GitHub repo and upload everything inside this folder (index.html at the root).
2. Repo → Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repo>/`.
