# Student Portfolio & Academic Management Website
COS 106 – Introduction to Web Technologies (Term Project)

A responsive multi-page website built with HTML5, CSS3 and vanilla JavaScript.

## Structure
```
student-portfolio/
├── index.html        Homepage
├── about.html        About Me
├── projects.html     Projects
├── planner.html      Academic Planner (JS)
├── contact.html      Contact form (JS validation)
├── css/style.css     External stylesheet
├── js/
│   ├── main.js       Navigation, greeting, footer year
│   ├── planner.js    Add / complete / delete tasks
│   └── contact.js    Form validation
├── images/           Photo and project screenshots
└── media/            Audio / video files
```

## Before you submit
1. Replace "Your Name", the biography, education table and skills with your details.
2. Replace `images/profile.svg` with your photo (update the `src` in index.html, e.g. `images/profile.jpg`).
3. Replace project screenshots and the GitHub links in projects.html.
4. Replace `media/sample.wav` / the video source with your own media.

## Hosting (GitHub Pages)
1. Create a GitHub repo and upload everything inside this folder (index.html at the root).
2. Repo → Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repo>/`.
4. Submit the live link and the repo link.
